Privacy Policy

Last updated: 28 October 2026

This policy describes the current browser-based RigCraft 3D prototype. The product currently provides an interactive PC configurator and local build workspace. It does not currently offer user accounts, a signup or waitlist form, payment checkout, or user-upload features in the inspected application.

This page documents the implementation reviewed for this release. Hosting settings and third-party providers may process technical data independently. The project owner should review this notice against the final deployment and obtain jurisdiction-specific legal advice before production launch.

Information stored by the application

The build workspace uses your browser's local storage to remember the selected region and currency display preference, build names, and saved build snapshots. This data is stored on your device by the browser and is not intentionally sent to a RigCraft application server by the current frontend code. Anyone with access to your browser profile may be able to access this data.

You can remove this information by clearing site data in your browser settings. Clearing it may delete saved snapshots and preferences. Storage availability and retention depend on your browser and device.

Third-party scripts and network information

The 3D viewer currently loads the Three.js library from cdnjs.cloudflare.com and OrbitControls from cdn.jsdelivr.net. When your browser requests these files, the relevant content delivery provider and hosting/network intermediaries may receive technical request information such as your IP address, user agent, requested resource, and request time. Their own privacy policies and retention practices apply to their processing.

The current inspected application source does not intentionally include advertising pixels, analytics, or session-replay software. This statement is not a guarantee about the hosting provider, browser extensions, network intermediaries, or future changes. Re-check the deployed site's network requests when the application or hosting configuration changes.

Cookies and similar storage

The current workspace uses local storage for user-requested preferences and saved snapshots. The inspected application code does not intentionally set analytics cookies. Hosting infrastructure or third-party services may use their own technical storage or logs. Applicable consent requirements depend on the final configuration and the user's jurisdiction.

Accounts, marketing, and children

The current prototype does not provide account registration, a marketing mailing list, or an age-verification form. Do not submit sensitive personal information through build names or exported build files. If accounts, marketing, or child-directed features are added, this policy and the collection/consent design must be reviewed before launch.

Sharing and exports

Build snapshots can be exported as JSON by a user action. An exported file is under your control after download; take care when sharing it. The current prototype does not provide cloud-saved or publicly shared builds.

Retention and security

Browser-stored preferences and snapshots remain until removed by the user, browser, or device policy. The project does not currently operate an application account database for this prototype. No website can promise absolute security; keep your browser and device updated and avoid storing sensitive information in build names.

International users and your choices

RigCraft 3D may be accessed from different countries. Legal rights, consent requirements, and complaint routes vary by jurisdiction. Since the current prototype stores workspace data locally, browser site-data controls are the primary way to remove that local data. If future server-side collection is introduced, this section must be updated with the actual operator identity, processing purposes, legal bases where required, retention periods, recipients, and request process.

Contact and policy changes

For questions or to report a privacy concern about the current public project, use the project issue tracker. Do not include private or sensitive personal information in a public issue. A dedicated privacy contact should be provided before production launch if required by applicable law.

Material changes to collection, storage, hosting, or third-party services require this policy to be reviewed and updated. The date above should be changed whenever the policy is materially revised.

RigCraft 3D is an independent project. This policy is a transparent description of the inspected prototype, not a certification of legal compliance.
